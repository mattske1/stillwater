# 15-second demo

`stillwater-public-demo-15s.mp4` — a 15-second seamless Stillwater loop,
built with only the scripts in this repo and free hosted services.

1. `still.py` → `still.png` (FLUX.1-schnell, blue-dawn cairn in a creek
   with a small waterfall, long-exposure look)
2. `animate.py` → 5-second clip (Wan 2.2 image-to-video, static camera)
3. `weave.py --target 15` → this 15-second seamless loop

`still.png` is the exact still the loop was woven from.
